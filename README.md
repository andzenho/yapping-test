# Тест «Какой ты блогер» · Карина (Kerry Catt)

Мини-апп для Телеграма и обычная веб-страница: тест из 10 вопросов определяет тип блогера (Эксперт, Советчица, Правдорубка, Рассказчица, Своя в доску, Смелая, Гид), даёт темы и 5 готовых роликов, потом ведёт на анкету предзаписи Большой Игры 2.0.

Живой адрес: https://andzenho.github.io/yapping-test/

## Файлы

- `index.html`, `app.css`, `app.js`: сам тест. Без сборки, без фреймворков.
- `types.js`: тексты шести типов. **Руками не править**: генерируется из `raboty/test-types.md` проекта командой `python3 tools/build_types.py`.
- `assets/`: фото и стикеры Карины.
- `backend/`: Google Apps Script, пишет прохождения и анкеты в Google-таблицу.

## Настройки в `app.js` (блок CONFIG)

- `endpoint`: URL веб-приложения Apps Script. Пока пусто, ответы не уходят в таблицу.
- `channelUrl`: ссылка-приглашение в закрытый канал предзаписи. Пока пусто, после анкеты кнопка ведёт к команде (@kerryhelper).

## Метка источника

Ссылка с `?src=reels12` пишет в таблицу источник `reels12`. В Телеграме то же самое делает `startapp=reels12`.

## Локальный запуск

```bash
python3 -m http.server 8850
```
